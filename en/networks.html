01. Addresses and Protocols — Every Device's Identity

Every device on the network has two addresses: IP, its changeable logical address, and MAC, its fixed physical address engraved in the network card.

🏠 Analogy: An IP address is like your home address (it changes when you move to a new house), while a MAC address is like your national ID number (fixed wherever you go). The TCP mail carrier knocks and confirms the parcel arrived intact, while UDP tosses the parcel over the fence and walks away — faster, but with no guarantee.
🔢

IP Address

It consists of 4 Octets, and each octet can hold 256 values (0–255). The device's address must be in the same Subnet as the local network.

🪪

MAC Address

The address used to connect to an Ethernet network — the fixed physical address of the network card.

🔄

DHCP — A Changing Address

The DHCP protocol gives the client device an IP address dynamically (changing) — not a Static one (a trap!).

✅

TCP or UDP?

TCP is responsible for accuracy and ensuring data arrives correctly — attributing that to UDP is a recurring trap! UDP is faster but offers no guarantee.

🧅

Network Layers

The network access layer defines the physical communication methods with the local network ✓. The IP protocol belongs to the Internet layer — while the link layer's protocol is Ethernet (a trap!).

🛠️

Tools & Systems

Wireshark helps in managing and maintaining the network · Linux is an open-source system widely used for servers and networks · the Network File System NFS was developed by Sun Microsystems.

02. Connecting Devices and the Star Topology

The Star topology is the most famous network structure: every device connects to one central point:

⭐

The Heart of the Star

The central focal point of the star structure is the Switch. A concentrator is used to form the star topology — and the answer may accept Hub, Switch, or Router depending on the available options.

📉

Hub or Switch?

The Hub is less commonly used than the Switch — because the hub broadcasts to all devices, while the switch sends only to the intended device. The phrase "more commonly" is a trap!

🎴

Network Card NIC

The Network Interface Card is what translates digital data into electrical signals — attributing this to "connecting devices" in general is wrong (a trap!).

🖧

The Two Operating Models

Client-Server networks are the ones that require a server device with special specifications to provide the service — while in Peer-to-Peer networks the devices are equal, with no central server (a classic mix-up trap!).

03. Cables and Ports

This part's questions are small details to memorize as they are:

📺

HDMI Port

Used as a port to connect high-definition TVs.

🖥️

VGA Port

An old port — its image quality is lower, so the phrase "used in high-resolution displays" is wrong (a trap!).

🧵

Coaxial Cable

It consists of 4 parts to reduce signal interference — not five (a trap!).

🔀

Crossover Cable

The crossover cable is used to connect similar devices (of the same type): computer to computer, switch to switch.

📡

Wireless Communications

Wireless Communications transmit data over electromagnetic waves.

04. Internet Connection Types and the Cloud

Who are leased lines for? Is DSL speed constant? And which cloud is the Windows platform?

🏢

Leased Lines

Leased Lines are the best option for large companies, institutions, and universities that need high speed and reliability — not for individuals (a trap!).

📞

DSL Line

With DSL, the Internet speed remains constant for the customer ✓ — while the phrase "constant by the customer" is wrong; the consistency is guaranteed by the service provider (a preposition trap!).

☁️

The Windows Cloud

The Windows platform is considered a type of Public cloud.

🛒

Amazon AWS

One of the most famous online infrastructure (IaaS) providers — describing it as a "Software provider" is wrong (a trap!).
