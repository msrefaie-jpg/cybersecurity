01. Instructional Design — Steps to Memorize in Order

Ordering questions ask you to click the steps in their correct order. Memorize the order of the eight steps of instructional design and writing the educational scenario (the memo version is approximate in wording — read the steps in your actual question before answering):

📝

Steps of Instructional Design and Writing the Educational Scenario

  1. Formulate the learning objectives.
  2. Define the tasks and learning activities required of the learner.
  3. Observe the learner, identify behaviors, and write behavioral statements for the objectives.
  4. Prepare tests within defined measures.
  5. Set general strategies to guide the learning process.
  6. Prepare, organize, and structure the learning content in a sequential, engaging way.
  7. Refine and develop the courses.
  8. Define assessment strategies and tools.
🎬

Digital Content Production

It starts with instructional design first, then filming and editing, then graphics, and finally content development — the reversed phrasing "develop the content, then design it" is wrong (trap!).

👨‍🏫

The Expert SME

The Expert (SME) is the academic supervisor in the instructional design process. After the educational scenario is written, it is distributed to the team — the statement "it is not distributed" is wrong.

🎥

Camera Shots

The Long Shot has 3 forms · the Identical Shot is used when filming a dialogue between two people · and the very close-up shot is not advised for course design, nor for filming motion, because it magnifies everything.

💾

Save Order in Storyline

Steps to save a lesson: open the program interface ← File menu ← Save As command ← choose the name and save location ← click Save. Steps to add a Marker: open the slide ← Insert tab ← Marker ← pick an icon ← click where to place it.

02. Learning Platforms — Moodle, Teams, and Edmodo

Moodle Moodle has the most questions in this section — memorize the "Blocks" and their commands:

🎓

Moodle — Basics

An open-source program distributed under the GNU General Public License (not "GNP"!) and built with PHP. The user login form is Log in to LMS, and blocking login is the administrator's responsibility.

🧱

Moodle — Blocks and Commands

The Html block lets you use formats like Word · the Messages block shows messages from other subscribers (messages can be hidden) · the forums icon is in the Activities block · to add a forum inside the course: Add an activity · to upload a folder or important content: Resources · you can also create a discussion forum for a specific topic, hide an activity, and insert labels.

💬

Microsoft Teams

Channel posting permissions are set from the three dots next to its name ✓ · to get the attention of all channel members we write @channel · the teacher grades assignments from the Assignments tab ✓ · and anyone can request to join public groups (private ones, no — the "no one can" trap!).

⏱️

Edmodo

Helps save time by posting a specific topic on the platform and then discussing it with students ✓.

03. Meetings & Interaction — Zoom, Mentimeter, and Quizlet

Three tools that bring a remote class to life: meetings, live polling, and self-testing:

🎦

Zoom

A cloud video conferencing tool that hosts one-on-one or group meetings ✓ · recording via the Record icon in the toolbar ✓ · the mobile version saves recordings to the Zoom cloud only ✓ · and Zoom Rooms can only be accessed by specific members — "anyone" is a trap!

📊

Mentimeter

Collects feedback via polls, quizzes, word clouds, and Q&A inside the presentation ✓ · lets you control presentations from a smartphone ✓ · and for teacher evaluation: New survey.

🃏

Quizlet

Test yourself anytime to assess what you have learned: languages, history, science, or any other field ✓ — and it is ideal for anyone who wants to learn languages with their grammar ✓.

🗺️

Lucidchart

SVG images can be imported into it — the statement "cannot" is wrong (trap!).

04. Content Authoring Tools — Camtasia, Storyline, and Canva

The section's most common question type: "from which menu?" in Camtasia and Articulate Storyline — memorize the menus, then the shortcuts:

🎞️

Camtasia — Menus

Add multimedia to the library: Library menu · timeline marker: Modify · add shapes: Annotations · convert to a placeholder and jump to the next media: Edit · adjust transitions between scenes and slide effects: Transitions.

✂️

Camtasia — Capabilities

Offers Full HD resolution ✓ · splitting a video in two lets you edit each part separately ✓ · record audio later with Voice Narration ✓ · and it does not require Adobe After Effects — each program is fully independent (trap!).

📖

Articulate Storyline

Add animation to text and images: Animations menu · add questions: Slides menu ✓ · control the workspace and project size: Design menu · the publish icon is in the Home menu · change a character's state via the Timeline · it embeds its output in web pages ✓ · and hovering the cursor over a shape changes its color from blue to red.

🎨

Canva

Works from the main website page on desktop or mobile ✓ · deleted designs are recovered from the Trash (not "templates"!) · you can create a transparent background and control zooming in/out · it includes many ready-made graphics and lets you upload your own elements ✓ · the free content calendar is for paid subscriptions (trap!) · access: by searching for Canva.com.
