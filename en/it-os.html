Memo Explanations

A simplified explanation with everyday analogies for everything in the memo's IT and operating systems section.

01. Computer Components — What's Inside the Box?

A computer consists of two kinds of components: physical components Hardware that can be seen and touched, and software components Software that cannot be seen or touched, though we see the effect of their work.

🏢 Everyday analogy: A computer is like a company: the system unit is the company building, the CPU is the manager who executes decisions, and inside the manager's office are two departments: the arithmetic and logic unit (the accountant doing the calculations) and the control unit (the head of operations directing everyone — which is why it's described as "the brain of the computer").
📦

System Unit System Unit

The metal box that contains almost all of the computer's basic components. Careful: it is not the "power unit" — that's a component inside it that only supplies electricity.

🧠

Processor CPU

"The brain of the computer" that executes all operations. Its speed is measured in megahertz (MHz), and its best-known makers are Intel and AMD. At its heart sits the arithmetic and logic unit (ALU).

🎛️

Control Unit Control Unit

Considered the brain of the computer — it directs the flow of data between units. The memo's trick question: "The memory unit is the brain of the computer" ❌ Correct: the control unit.

➕

Arithmetic & Logic Unit ALU

Performs arithmetic operations (addition, subtraction...) and logical operations (comparisons), and is located inside the central processing unit (CPU).

⌨️

Input & Output Units

Input: keyboard, mouse, scanner, microphone. Output: monitor, printer, speakers. And the function keys F1–F12 do different things in different programs.

🔌

Motherboard & Power Supply

The motherboard connects all components together, and the Power Supply feeds the device with electricity — it is not the system unit.

02. Memory & Storage — Where Does Your Data Live?

Click each memory type to understand its role:

🍳 Kitchen analogy: RAM is the prep counter — everything you're working on right now sits on it, and when the kitchen closes (power off) it is cleared completely. ROM is the kitchen's operating manual mounted on the wall — it never changes and never disappears. The hard disk is the pantry — everything stays stored there even if the kitchen closes for a year.
💽

Hard Disk HDD

The computer's main secondary storage device: a metal disk covered with a magnetic layer onto which data is recorded by a read/write head as it spins.

⚡

Solid-State Drive SSD

Stores data on flash memory (like a USB stick): no moving parts, faster, lower power consumption, and shock-resistant.

📏

Data Measurement Units

The bit (0 or 1) is the smallest unit → byte = 8 bits → kilobyte = 1024 bytes → mega → giga → tera... each unit = 1024 of the previous one.

💿

Other Media

CDs come in three types (read-only / write-once / rewritable), DVDs hold 7.4–17 GB, and USB flash drives go up to 2 TB.

03. Operating Systems — The Device's Manager

The operating system is the computer's backbone and the link between the user and the machine. A computer can run without application software, but it can never run without an operating system — memorize this; it's a question that often appears reversed!

🪟

Windows

First release in 1985, announced by Bill Gates. Windows 10 (2015): Cortana + the Edge browser + the graphical Start menu. Windows 11: runs Android apps and games directly. Used by 95% of personal computer users.

🐧

Linux

A completely free, open-source system enjoying a high degree of freedom to modify, operate, distribute, and develop — don't attribute this feature to Windows in the exam!

🤖

Android

An open-source system based on Linux, developed by Google and the Open Handset Alliance (OHA) — not Windows.

🍎

Mac OS

The first operating system to use a graphical user interface (GUI), and the memo's example of a multitasking system (along with Windows and Linux). MS-DOS is the example of a single-tasking system.

04. Software & Applications

Computer software is divided into two main types: operating systems and application software.

🏢

The Microsoft Office Suite

Word, Excel, PowerPoint, Access, Outlook, Teams, OneDrive... The company's founder is Bill Gates. And Google Drive is not a Microsoft app — it's the famous exception question.

☁️

OneDrive

Microsoft's cloud storage service — it gives the user only 5 GB free (not 1 TB!) with paid upgrade options.

👨‍💻

Programming Programming

The process by which you achieve an idea or solve a problem by dividing the idea or problem into successive, repeatable steps — like a cooking recipe written step by step.

🦠

Malware Malware

Any program whose tasks — all or one of them — cause harm to the system: spying, sabotage, or draining resources (CPU, memory, network...).

⏱️

Timer & Calendar

Per the memo: to measure the duration of a task use Timer, and to plan events use Calendar. ⚠️ Note: these two answers are not stated verbatim in the official material (Calendar appears only in the list of accessory programs) — memorize them as exam answers from the memo.

05. Computer Types

Computers are classified by the nature of the data they process — and here the deliberate mix-up questions abound:

🌡️

Analog Analog

Captures real-world data (temperature, pressure) — it does not process digital data and does not use binary numbers.

🔢

Digital Digital

Works on digital data presented as binary numbers (0 and 1) — that's your personal computer and your phone.

🩺

Hybrid Hybrid

A combination of analog and digital — used in medicine (ECG) and fuel pumps. The memo tries to trick you by attributing this definition to the analog type!

📏 And by size too (from the official curriculum): the Supercomputer for massive research → the Mainframe for banks → the Mini (serves 5–300 users) → the Workstation for engineering design → the Micro/PC, which is your personal device.

08. What the Memo Doesn't Cover

The memo's questions focus on components and operating systems, while the official material (123 pages) covers more — new questions may come from it:

🎓

The FDTC certificate structure

10 training programs coded BIT 01 – BIT 10 (this section is BIT 01); passing requires 7 programs: 5 mandatory + 2 elective, and each program lasts two days. The exam is available in Arabic or English.

🧬

BIOS & booting

Basic Input Output System: a program stored in ROM responsible for the basics of the computer's operation and its initial startup — which is why ROM is "useful in the initial operation".

🔢

The full chain of measurement units

Bit → byte (8 bits) → KB → MB → GB → TB → PB → EB → ZB → YB, each unit = 1024 of the previous one.

🔌

USB versions

1.1 (1998) → 2.0 (2000, at 480Mb) → 3.0 (2008) → 3.1 (2015) → 3.2 (2018) → 4.0 (2019, at 40Gb).

🕰️

Milestones in Windows history

2.0 (1987): first versions of Word and Excel · 95: first 32-bit standard and the Start menu · ME and Vista: both labeled failures · 10 (2015) · 11 (officially announced 2022): Snap Layouts and built-in Teams.

⚙️

The operating system's six functions

Hardware management, main memory management, processor management, file management, providing the user interface, and enabling programs to run.

🖥️

Windows 11 minimum requirements

A 1GHz dual-core 64-bit processor, 4GB RAM, 64GB storage, a TPM 2.0 security chip, and UEFI with Secure Boot — an English table in the material that's a strong exam candidate.

🛡️

Windows security & sign-in

Windows Security colors: green (healthy) / yellow (recommendation) / red (immediate warning). And Windows Hello: sign-in by face or fingerprint, a picture password, and dynamic lock that locks the device when your phone moves away. A strong password: at least 8 characters.

🌐

The internet & modern technologies

The internet began in 1969 as ARPANET to support American military research. The material also defines: artificial intelligence and its three applications, cloud computing, the Internet of Things (IoT), and the difference between virtual reality (VR) and augmented reality (AR).

🇪🇬

Egyptian platforms

The Digital Egypt platform digital.gov.eg for government services, and the Egyptian Knowledge Bank ekb.eg — free for all Egyptians of all ages.

📄

Files & extensions

A file name can't exceed 255 characters, and most extensions are 3 letters: docx Word, xlsx Excel, pptx PowerPoint, mp3 audio, mp4 video, jpg images, zip/rar compressed.

🗓️

Microsoft Office through history

Announced by Bill Gates on August 1, 1988; the first release came in 1990 (only Word, Excel, and PowerPoint), and today it's available in 35 languages. Access is a database management system (DBMS).
