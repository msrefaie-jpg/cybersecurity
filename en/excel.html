01. Basics & References — The Language of Excel

The Workbook is the whole file, containing Worksheets, and each sheet is a huge grid of cells: 16,384 columns × 1,048,576 rows.

📒 Analogy: the workbook is a whole notebook, each worksheet a ruled page in it, and each cell a box on that page with an address made of the column letter and row number (like B3). When your formula uses the "box's address" instead of its value, the result updates automatically whenever its contents change — the single most important idea in all of Excel.
🎯

Relative and Absolute References

The two reference types: relative, which changes when copied, and absolute, which is fixed with a $ sign (like $A$1). To toggle between them while editing: the F4 key. ⚠️ "Relative reference and percentage reference" is a recurring wrong statement!

🔢

Counting Cells in a Range

The range L11:N15 = 3 columns (L,M,N) × 5 rows (11–15) = 15 cells. Always multiply the number of columns by the number of rows.

📋

Paste Special Transpose

Turning values from horizontal to vertical (or vice versa) via Paste Special — on the Home tab.

✅

Data Validation

Controlling a cell's content via Data Validation in the "Data Tools" group on the Data tab — it's also how the drop-down list is created (provided a cell range containing the options exists).

🧊

Freezing

Keeping an area of the worksheet visible while scrolling through the rest of the columns and rows — perfect for pinning the header row.

🔀

Sort or Filter?

Sort = arranging in ascending/descending order. Filter = temporarily hiding rows that don't match the condition and showing those that do. Mixing them up is a recurring trap!

⌨️

Quick Selections

Select a row within a range: Ctrl+Shift+Arrow · Select a range up to the last data: Ctrl+Shift+End · Insert a new row: right-click the row header, then "Insert".

🪄

AutoFill

To fill numbers in a sequential pattern, enter two values (not one) so Excel understands the step between them, then drag the fill handle.

03. Functions — Memorize by Family, Not Scattered

The exam's favorite question: "Function X belongs to the … family". Memorize the family before the function:

🔤

Text Functions Text

PROPER capitalizes the first letter of each word · LOWER converts all uppercase letters to lowercase. ⚠️ "PROPER is mathematical" is a recurring trap — it is a text function.

➗

Math Functions Math

ROUND for rounding · RANDBETWEEN returns a new random integer every time the sheet recalculates · SUMIF sums with a condition — its third argument can be omitted when the condition range is the same as the sum range.

📈

Statistical Counting Functions

COUNT counts numeric cells only · COUNTA counts numeric and text cells together · COUNTIF(F3:F6,"passed") counts with a condition — beware: the option without the quotation marks « " " » is a planted wrong answer!

🔎

Lookup Functions Lookup

VLOOKUP searches for a value, then returns its data from a specific column · MATCH searches for a value, then returns its order in the column. (data → VLOOKUP, order → MATCH).

📅

Date & Time Functions

NOW returns the serial number of the current date and time · TODAY returns the date only. Both belong to the Date & Time family — not the "general functions"!

🧮

SUBTOTAL and Brackets

When using SUBTOTAL, 3 levels appear at the side of the sheet. And operations enclosed in brackets are the first thing Excel calculates in a formula — not the last.

🧠 Memory trick: V in VLOOKUP = Value — "fetch the value and its data", while MATCH = "match it and tell me its place". NOW = the full current moment with date and time, whereas TODAY = just today's date.

04. Charts & Printing

Excel turns table numbers into a chart to make the data easier to interpret and the results quicker to reach:

📊

Moving a Chart

To move a chart to a new sheet or another file: the "Move Chart" command on the Design tab. Pictures, however, have no "move" — only copy or cut and paste (trap!).

🏷️

Chart Title

A chart must have a title describing its overall content, and its usual position is at the top of the chart — not the bottom (trap!).

🖨️

Print Titles Print Titles

To repeat specific rows at the top of every printed page: Print Titles → Rows to repeat at top on the Page Layout tab.

🖼️

Sheet Background

A picture can be used as a worksheet background for display only — it does not print. To actually print gridlines: the Print option under "Gridlines" on the Page Layout tab.

🔗

Linking Sheets

Two worksheets can be linked with the results shown in a third, and calculations can span more than three sheets — Excel lets you combine multiple sheets and calculate across them.

🪟

Switching Windows

Moving between open workbooks: Switch Windows on the View tab — not "Page Layout" (trap!). Zoom in/out also lives there.

05. Errors & Protection

A # at the start of a cell = Excel is complaining. Memorize the reason for each complaint:

❓

#NAME?

Appears when the equation needs to be corrected — usually a misspelled function name.

🔢

#NUM!

Appears when the formula or function contains an invalid numerical value.

🟩

The Green Triangle

The memo's answer: it appears beside a cell that is formatted as text but contains numbers (flag or triangle: two names for the same mark). ⚠️ Not stated verbatim in the official material — it says the red triangle indicates a comment.

🔐

Protection in Two Ways

A worksheet is protected in two ways, and users can be prevented from creating layouts or macros, moving/copying sheets, or making any edits. But what sheet password protection does NOT prevent: unauthorized users opening the sheet!

🔒

Locking Cells and Hiding Formulas

Cell locking and formula hiding will not take effect until the workbook or worksheet is protected — locking alone, without protection, does nothing.

💬

Comments

Inserting a comment in a cell and navigating between comments: the Review tab — not "View" (trap!).

07. What the Memo Doesn't Cover

The official material (144 pages) adds entire topics with no memo questions:

🎓

The Section's Place in the Certificate

Spreadsheets is program BIT 04 of the FDTC programs, built on Excel, whose interface consists of: the title bar, Quick Access Toolbar, the Ribbon, the formula bar, and the status bar.

🚨

The Complete Error Table

The material lists all errors: #DIV/0! division by zero · #N/A value not available · #NAME? unrecognized name · #NULL! invalid intersection · #NUM! invalid number · #REF! deleted cell reference · #VALUE! wrong argument type.

🧩

Advanced Logical Functions

IFS tests up to 127 conditions · ISERROR checks whether a value is an error · IFNA handles the #N/A error with a fallback value.

📉

Statistical Analysis

CORREL computes the correlation coefficient between two data sets. For advanced analysis: the Analysis ToolPak and Solver add-ins are enabled from Options → Add-ins.

🧷

Consolidate

To combine data from more than 3 worksheets into one sheet: the "Consolidate" command on the Data tab.

📁

xlsx or xls?

The modern .xlsx extension is roughly 3 times smaller than the old .xls extension (versions 97–2003).

⌨️

Shortcuts from the Material

Ctrl+T create a table · Alt+Enter new line within a cell · Ctrl+; insert today's date · Ctrl+F4 closes the workbook while Alt+F4 closes Excel entirely.

🧮

SUBTOTAL — The Extra Detail

The levels are 3 when replacing the current subtotals — and become 4 levels if you uncheck "Replace current subtotals".
