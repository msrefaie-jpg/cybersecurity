# 🛡️ الأمن السيبراني ببساطة — دليل تفاعلي لغير المتخصصين

دليل تفاعلي باللغة العربية يشرح مفاهيم **الأمن السيبراني** بأسلوب مبسّط لغير المتخصصين، مُستخلص من قسم الأمن السيبراني في مذكرة أسئلة مقرر **التحول الرقمي** (إصدار يونيو 2026).

## 🔗 رابط الدليل التفاعلي

**افتح الدليل من هنا:** https://msrefaie-jpg.github.io/cybersecurity/

> ملاحظة: يتطلب الرابط أعلاه تفعيل GitHub Pages من إعدادات المستودع (Settings → Pages → Branch: main). حتى ذلك الحين يمكن تحميل ملف `index.html` وفتحه مباشرة في أي متصفح — فهو يعمل بدون إنترنت.

## 📚 ماذا يحتوي الدليل؟

| القسم | الوصف |
|---|---|
| **المفاهيم الأساسية** | ما هو الأمن السيبراني؟ الهجوم السيبراني، التشفير، كلمات المرور، النسخ الاحتياطي — بتشبيهات من الحياة اليومية |
| **مثلث حماية المعلومات (CIA)** | شرح تفاعلي للسرّية والسلامة والتوافر |
| **التهديدات** | الفيروسات، الديدان، برمجيات الفدية، التصيّد الاحتيالي، الهندسة الاجتماعية، وغيرها — مع طريقة الوقاية من كل منها |
| **أنواع المخترقين** | القبعات البيضاء والسوداء والرمادية والزرقاء |
| **احمِ نفسك** | قائمة تفاعلية بأهم 8 عادات وقائية مع مؤشر لدرجة حمايتك |
| **اختبر نفسك** | اختبار من 10 أسئلة مأخوذة من أسئلة المذكرة مع شرح لكل إجابة |
| **قاموس المصطلحات** | 16 بطاقة تفاعلية قابلة للقلب للمراجعة السريعة |

## 🎯 لمن هذا الدليل؟

- أي شخص يريد فهم أساسيات حماية نفسه على الإنترنت بدون خلفية تقنية.
- طلاب مقرر التحول الرقمي الراغبين في مراجعة قسم الأمن السيبراني بطريقة ممتعة.
- المعلمون والمدرّبون الذين يحتاجون مادة عرض مبسطة.

## 💡 كيف تشاركه؟

المستودع عام — شارك رابط الصفحة التفاعلية أو رابط المستودع مع أي شخص ليستفيد.
