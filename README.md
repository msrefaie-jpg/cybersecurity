# 🛡️ الأمن السيبراني ببساطة — دليل تفاعلي لغير المتخصصين

دليل تفاعلي باللغة العربية يشرح مفاهيم **الأمن السيبراني** بأسلوب مبسّط لغير المتخصصين، مُستخلص من قسم الأمن السيبراني في مذكرة أسئلة مقرر **التحول الرقمي** (إصدار يونيو 2026)، ومُطابَق مع **المادة التدريبية الرسمية «الأمن السيبراني 2026»** الصادرة عن المجلس الأعلى للجامعات (FDTC) بالتعاون مع EG-CERT.

## 🔗 رابط الدليل التفاعلي

**افتح الدليل من هنا:** https://msrefaie-jpg.github.io/cybersecurity/

> ملاحظة: يتطلب الرابط أعلاه تفعيل GitHub Pages من إعدادات المستودع (Settings → Pages → Branch: main). حتى ذلك الحين يمكن تحميل ملف `index.html` وفتحه مباشرة في أي متصفح — فهو يعمل بدون إنترنت.

## 📚 ماذا يحتوي الدليل؟

| القسم | الوصف |
|---|---|
| **المفاهيم الأساسية** | ما هو الأمن السيبراني؟ الهجوم السيبراني، التشفير، كلمات المرور، النسخ الاحتياطي — بتشبيهات من الحياة اليومية |
| **مثلث حماية المعلومات (CIA)** | مثلث SVG تفاعلي للسرّية والسلامة والتوافر |
| **التهديدات** | الفيروسات، الديدان، برمجيات الفدية، التصيّد الاحتيالي، الهندسة الاجتماعية، وغيرها — مع طريقة الوقاية من كل منها |
| **أنواع المخترقين** | القبعات البيضاء والسوداء والرمادية والزرقاء (مع إبراز الإجابة المعتمدة وسندها من المنهج الرسمي) |
| **من المادة الرسمية** | موضوعات يغطيها المنهج الرسمي ولا تغطيها المذكرة: معادلة المخاطر، EG-CERT وESCC، بروتوكول TLP، القوانين المصرية، التنمر الإلكتروني، وغيرها |
| **أسئلة متوقعة** | 22 سؤالاً تدريبياً جديداً مصوغاً من الفصول غير المغطاة في المذكرة، بنفس أسلوب الامتحان (إنجليزي + ترجمة + شرح) |
| **مصيدة الكلمات المطلقة** | نمط أسئلة صح/خطأ الخادعة: كلمات مثل always تقلب العبارة — مع تظليل كلمة المصيدة |
| **احمِ نفسك** | قائمة تفاعلية بأهم 8 عادات وقائية مع مؤشر لدرجة حمايتك (يُحفظ تقدمك في المتصفح) |
| **اختبر نفسك** | اختبار من 10 أسئلة بالصياغة الإنجليزية الأصلية كما في الاختبار الفعلي + ترجمة عربية وشرح لكل إجابة |
| **قاموس المصطلحات** | 27 بطاقة تفاعلية قابلة للقلب مع فلاتر تصنيف، وكل تعريف بالعربية والإنجليزية |

## 🎯 لمن هذا الدليل؟

- أي شخص يريد فهم أساسيات حماية نفسه على الإنترنت بدون خلفية تقنية.
- طلاب مقرر التحول الرقمي الراغبين في مراجعة قسم الأمن السيبراني بطريقة ممتعة.
- المعلمون والمدرّبون الذين يحتاجون مادة عرض مبسطة.
